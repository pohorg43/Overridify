# Overridify

<p align="left">
  <strong>🌐 Language / Язык:</strong>
  <a href="README.md">English</a> | <b>Русский</b>
</p>

**Инструмент для глубокого низкоуровневого анализа и выборочного переопределения системных флагов Android.**

В отличие от подавляющего большинства твикеров со слепыми списками из интернета, **Overridify** использует принцип объективной истины (*Ground Truth*). В утилиту встроен собственный микросканер на Си (`overridify-scan`) и многопоточный анализатор Dalvik DEX. Прямо на устройстве дизассемблируется машинный код ARM64 системных библиотек/бинарников и парсится байткод системных `jar`-фреймворков и APK. Это позволяет с высокой точностью определить, считывается ли флаг кодом прошивки на самом деле, каков его заводской дефолт, или это мёртвый груз.

Помимо аудита, утилита включает интеллектуальный менеджер пресетов: проверенные оптимизированные профили, интерактивный конструктор собственных наборов с валидацией флагов в реальном коде прошивки и механизм быстрого экспорта/импорта конфигураций.

## Основные возможности

- **Точная детекция источников флагов** — показывает реального автора каждого свойства и оверрайда в живой системе: зашит ли он в код прошивки, переопределён через `build.prop`, выставлен инит-службами (`*.rc`), сохранён в постоянной памяти (`persist`) или внедрён конкретным установленным Magisk / KernelSU / APatch модулем.
- **«Радар мусора» и отлов неэффективных модулей** — сканирует активные свойства и выводит на чистую воду сторонние модули-«оптимизаторы», находя реальный мусор и плацебо:
  - Параметры чужих платформ (например, флаги MediaTek, прописанные в модуле на Snapdragon, и наоборот);
  - Устаревшие свойства AOSP с указанием точной версии Android, в которой чтение флага было удалено из системы (например, `deprecated A11+`);
  - Опечатки и никогда не существовавшие в коде Android твикерские выдумки.
- **Аудит машинных дефолтов (>80% точности)** — находит и отображает истинные заводские значения по умолчанию, зашитые компилятором в машинный код системных библиотек (включая таблицы `.data.rel.ro` и прологи функций) и байткод Dalvik DEX.
- **Умное управление пресетами и конструктор профилей** —
  - Готовые выверенные профили (*Vulkan UI Pipeline*, *SurfaceFlinger Vulkan*, *Ультра-плавность UI*, *Отклик сенсора*, *Игровой режим*) с проверкой конфликтов с другими модулями;
  - **Mali Guard и Qualcomm Guard** — автоматический нативный патч драйвера GPU Mali для безопасной работы Vulkan SurfaceFlinger без чёрного экрана (исправление дефекта `vkGetDeviceQueue2`), а также защита от мерцания на чипах Qualcomm;
  - Интерактивный конструктор: создание и редактирование своих пресетов со списком любых флагов `key=value` и мгновенной проверкой их наличия в бинарниках ROM;
  - Быстрый обмен: экспорт и импорт одиночных пресетов или целых паков одной строкой `OVRD1:` (Base64).
- **Полная оффлайн-автономия** — работает без интернета, внешних зависимостей и сторонних пакетов (`pkg install` не требуется). В модуль встроены автономный движок `mawk` и нативные бинарники на Си.
- **Двуязычный интерфейс (RU / EN)** — переключение языка на лету прямо в меню.

## Как читать результаты аудита

Каждое проверенное свойство в аудите выводится детальной карточкой:

```text
* debug.hwui.renderer
    Значение : [unset]
    Источник : aosp
    Сканер   : DEFAULT_STR: "skiagl"
```

### 1. Что означает «Источник» (`Source`)
Показывает, откуда операционная система берёт значение свойства:

| Источник | Расшифровка |
| :--- | :--- |
| **`aosp`** | Стандартный флаг чистого Android. Если значение `[unset]`, система гарантированно использует эталонный дефолт AOSP. |
| **`qti (caf)`** | Подтверждённый компонент платформы Qualcomm Snapdragon. |
| **`vendor (rom)`** | Заводской дефолт прошивки: число, булево значение или строка зашиты непосредственно в машинный код библиотеки компилятором. |
| **`unverified`** | Свойство не задано в системе (`[unset]`), а его дефолт вычисляется кодом динамически. Утилита честно указывает, что подтверждённого статического эталона в базе для него пока нет. |
| **`<раздел> (build.prop)`** | Свойство явно прописано в файлах прошивки (`/system`, `/vendor`, `/odm`, `/product`, `/system_ext`). |
| **`module (<имя>)`** | Свойство переопределено конкретным установленным Magisk / KernelSU / APatch модулем. |
| **`service (<имя.rc>)`** | Выставлено инит-сервисом Android (`*.rc`) при старте системы. |
| **`persist (/data)`** | Сохранено в постоянной памяти `/data/property`. |

### 2. Что означают «Вердикты сканера» (`Scanner`)
Результат статического анализа машинного кода ARM64 и байткода Dalvik DEX:

| Вердикт | Расшифровка |
| :--- | :--- |
| **`DEFAULT_BOOL (true/false)`** | Зашитый булевый дефолт. |
| **`DEFAULT_INT: <число>`** | Зашитый числовой дефолт. |
| **`DEFAULT_STR: "<текст>"`** | Зашитый строковый дефолт. |
| **`DYNAMIC_DEFAULT`** | Бинарник реально обращается к свойству, но значение по умолчанию вычисляется динамически во время выполнения. |
| **`NOT_FOUND_IN_BINARY`** | Свойство активно в системе (`getprop`), но в проверяемой библиотеке его чтения нет, либо это никем не читаемый рудимент. |

## Интерфейс и управление

Управление реализовано через интерактивный терминальный TUI-интерфейс с горячими клавишами, а также через быстрый скриптовый CLI.

### Запуск интерфейса в Termux

```bash
overridify
```

*(Модуль автоматически создаёт ярлык при установке, поэтому утилита доступна сразу без перезагрузки и без ручного ввода `su`, либо классически через `su -c overridify`).*

### Быстрые CLI-команды

```bash
overridify audit [подсистема|full]   # Аудит выбранной подсистемы или полный аудит прошивки
overridify radar                     # Сканирование системы и модулей на мусорные свойства
overridify preset [команда]          # Управление пресетами, экспорт и импорт шифров OVRD1
overridify search <запрос>           # Поиск нужного свойства по системным бинарникам и DEX
overridify export [путь]             # Экспорт подробного отчёта аудита (по умолчанию на /sdcard)
overridify help                      # Справка по всем командам CLI
```

## Системные требования

- **Архитектура:** ARM64 (`aarch64`)
- **Версия Android:** 6.0 Marshmallow и выше (**SDK 23+**) *(для полного разделения разделов Project Treble рекомендуется Android 8.0+ / SDK 26+)*
- **Root-среда:** Magisk 20.4+, KernelSU (и его форки) или APatch
- **Терминал:** [Termux](https://github.com/termux/termux-app)

---

## Установка

1. Скачайте последний архив `Overridify-v*.zip` из раздела [**Releases**](../../releases).
2. Установите модуль через менеджер Magisk / KernelSU / APatch.
3. Откройте Termux и введите `overridify`.

## Сборка из исходников

Нативные бинарники (`overridify-scan` и `mali-patcher`) компилируются автоматически через [GitHub Actions CI](.github/workflows/build.yml) при каждом обновлении с помощью Android NDK под **API 23 (`aarch64-linux-android23-clang`)**.

Сборка вручную:

```bash
# Прямо на устройстве в Termux:
clang -O3 -Wall src/overridify-scan.c -lz -lpthread -o bin/overridify-scan
clang -O3 -Wall src/mali-patcher.c -o bin/mali-patcher

# Кросс-компиляция на ПК через Android NDK (API 23+):
$NDK/toolchains/llvm/prebuilt/linux-x86_64/bin/aarch64-linux-android23-clang \
    -O3 -Wall -s src/overridify-scan.c -lz -o bin/overridify-scan
$NDK/toolchains/llvm/prebuilt/linux-x86_64/bin/aarch64-linux-android23-clang \
    -O3 -Wall -s src/mali-patcher.c -o bin/mali-patcher
```

## Структура проекта

```text
overridify/
├── module.prop                  # Метаданные модуля
├── customize.sh                 # Установщик (сохраняет конфиг и кастомные пресеты при обновлении)
├── uninstall.sh                 # Скрипт чистой деинсталляции
├── skip_mount / skip_mountify   # Маркеры изоляции монтирования
├── bin/
│   ├── overridify               # Главный TUI/CLI движок модуля
│   ├── overridify-scan*         # Нативный ARM64 ELF/DEX микросканер (собирается в CI)
│   ├── mali-patcher*            # Нативный патчер драйвера GPU Mali (собирается в CI)
│   └── mawk                     # Встроенный быстрый интерпретатор AWK
├── src/
│   ├── overridify-scan.c        # Дизассемблер ARM64 и анализатор байткода DEX (Си)
│   └── mali-patcher.c           # Бинарный патчер vkGetDeviceQueue2 (Си)
├── common/
│   ├── database/                # База жизненного цикла AOSP, цели аудита и профили пресетов
│   └── languages/ru.sh          # Русская локализация
└── .github/workflows/build.yml  # Автосборка бинарников и упаковка релизного ZIP в GitHub Actions
```

> `*` Файлы компилируются из `src/` автоматически в GitHub Actions CI и упаковываются в готовый релизный архив.
